# 24Flight Desktop
### Internal name: 24FlightSystem
Downloadable things for 24Flight. Includes autopilot and other things.

## C++ Essentials
You will require these for the respective os that you are running on

### Windows:
Visual Studio 2026(not Visual Studio Code, Visual Studio)(you will need to have desktop development with c++ enabled for everything)
MSYS64 with g++ and etc installed
VScode(preferably newest version)
Cmake
### MacOS(intel, not M series):
Cmake
VScode(preferably newest version)
g++ installed with brew
### Linux:
VScode(preferably newest version)
g++ installed
cmake
